# StudyFlow AI — Logo Variants & Color Palette

## Primary recommendation

The core mark combines an **open book** (academic learning) with an **ascending learning-progress line**. Use the horizontal transparent logo on desktop headers and the app icon for smaller UI surfaces.

## Suggested usage

- **Desktop navigation:** Primary horizontal logo on a white or pale background.
- **Dark sidebar:** Dark-background horizontal logo; test legibility at the actual displayed size.
- **Favicon:** Blue square icon, exported at multiple resolutions.
- **Status colors:** Amber for deadline warnings, red for genuine errors/conflicts, green for completion. Do not rely on color alone to convey status.
- **Clear space:** Keep at least 16px around the logo in the main navigation bar.

**Source fidelity note:** The exported transparent assets were cropped and processed from the original raster logo artwork. They are not original editable vectors. The colors are consistent implementation recommendations; the original icon includes gradient shades.
